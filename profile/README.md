## Who we are

ArmontSys builds the systems businesses run on: custom applications, the integrations that tie them to the rest of the business, and the services that have to be fast and reliable underneath. We are an **official Claris partner**, delivering FileMaker solutions from design through integration to long-term support. Alongside that platform work, we do modern web and application development on both the backend and the frontend.

## What we do

| | |
|---|---|
| **Claris FileMaker solutions** | Custom apps for iOS, macOS, Windows and the web; server setup; and modernisation and enhancement of existing solutions, across all modern FileMaker versions |
| **FileMaker integration** | Plug-in and API development, connecting FileMaker to Oracle, Microsoft SQL Server and MySQL, and hardware plug-ins for RFID, biometrics and scanners |
| **FileMaker on the web** | Web solutions on the FileMaker platform through WebDirect and Custom Web Publishing, with PHP and other web technologies |
| **Python backends and automation** | Async I/O, task queues and ETL, with packaging, CI/CD and observability, in type-hinted, tested codebases |
| **Django applications** | REST APIs with Django REST Framework, authentication and admin, ORM and caching, Celery tasks, PostgreSQL and production deployment |
| **Rust services** | High-performance microservices, CLI tools, FFI and performance-critical modules, with safe concurrency and async |
